# ⚡️ AI Pricing Calculator (v4.0 Dmitry & Dima Studio)

**Умный персональный калькулятор стоимости digital-проектов (Personal Pricing Engine)**, созданный специально по стандартам студии цифровой разработки Dmitry & Dima (v4.0).

---

## 🚀 Ключевые возможности

1. **Математический Pricing Engine (без галлюцинаций AI в расчетах)**:
   - Формула: `Base + Volume (Pages, Screens, Components) + Additional Works = Subtotal`
   - Итоговая смета: `Subtotal × Complexity × Urgency × Discounts = Project Price`
   - **Диапазон вместо ложной точности**: отображение `Рекомендуемой стоимости` (напр. 147 000 ₽) и рабочего диапазона (130k — 165k ₽).
   - Защита минимального чека студии (`minimumProjectPrice`).
   - Студенческий / волонтерский трек (разработка по себестоимости, бесплатная 30-мин консультация).

2. **Три режима расчета**:
   - ⚡️ **QUICK**: Экспресс-оценка за 5 простых вопросов прямо во время звонка с клиентом (за 30 секунд).
   - 🛠 **STANDARD**: Детальная форма с тонкой настройкой страниц, экранов в Figma, 14 модулей работ, сложности и сроков.
   - 🧠 **AI ANALYSIS**: Вставка сырого текста клиента из Telegram / почты. AI преобразует хаос в структурированные параметры и **находит скрытые неучтенные работы** (например, напоминает добавить CMS к каталогу товаров).

3. **Сравнение сценариев (BASIC / STANDARD / PREMIUM)**:
   - Наглядная матрица из трех пакетов для обсуждения объема задач, а не скидок.

4. **Аргументация «Why this price?»**:
   - Список понятных для бизнеса факторов ценообразования для уверенности на переговорах.

5. **Генератор клиентского предложения (Client Quote)**:
   - Без внутренних коэффициентов.
   - 1-клик копирование в Telegram с эмодзи и структурированным текстом в тоне «Business Cool».
   - Кнопка «Печать / Экспорт в PDF».

6. **История проектов & «My Pricing»**:
   - Сохранение смет в `localStorage`, экспорт и импорт в JSON.
   - Редактирование всех базовых ставок под себя.
   - Поддержка официального Google Gemini 3.8 Flash SDK + локальный NLP-парсер, работающий офлайн.

## 💻 Запуск и разработка

```bash
# 1. Перейти в папку проекта
cd C:\Users\User1\.gemini\antigravity\scratch\ai-pricing-calculator

# 2. Запуск локального сервера разработки
npm run dev

# 3. Запуск тестов математического движка
npm test

# 4. Продакшн сборка
npm run build
```

Сервер разработки будет доступен по адресу: `http://localhost:5174/`
